# 终端优先远程控制产品设计文档

## 1. 产品定位

本产品是一款面向个人用户的免费手机远程控制工具。第一版以 iOS / Android 手机连接个人 macOS 电脑为核心场景，默认进入远程终端，让用户可以快速输入命令、查看输出、管理文件；远程桌面作为辅助能力，用于查看 GUI、处理弹窗、观察浏览器或桌面运行结果。

产品不是传统“远程桌面 App”，而是“手机上的远程终端控制台”。桌面控制是兜底，终端、文件和设备能力是主线。

## 2. 核心问题

现有手机远控软件常见问题：

- 付费墙过早，核心使用路径被限制。
- 连接流程复杂，跨网络连接不稳定。
- 手机操作桌面控件困难，误触高。
- 为了打开终端，需要先远控桌面，再用手机触控操作桌面终端，路径冗长。
- 广告或商业提示打断会话。
- 开发/运维场景下，命令、文件、进程、服务状态没有被当作一等能力。

本产品从第一性原理出发，认为远程控制的本质是：把用户意图安全、低延迟、低误触地传到远端机器，并把远端状态清晰返回手机。对目标用户来说，最常见的意图不是“操控整个桌面”，而是“打开终端，输入命令，查看结果”。

## 3. 目标用户

MVP 目标用户：

- 使用 macOS 的个人开发者、独立开发者、学生、技术爱好者。
- 需要在外出时用手机查看项目、执行命令、重启服务、拉取代码、查看日志的人。
- 偶尔需要查看桌面画面或处理 GUI 弹窗，但主要任务在终端完成。

后续扩展用户：

- Windows 用户，默认使用 PowerShell。
- 轻量运维用户，需要查看服务状态、端口、日志、后台任务。
- 多设备用户，需要在多台电脑间快速切换。

## 4. 产品原则

- 终端优先：连接设备后默认进入命令面板，不默认进入桌面画面。
- 桌面辅助：桌面用于查看和点击，不作为主要操作入口。
- 免费可用：核心远控、终端、文件能力免费。
- 会话纯净：远控会话中不展示广告、不弹评分、不显示升级提示。
- 广告克制：广告只出现在会话外，或通过激励广告换取高成本资源。
- 安全透明：终端、文件、桌面能力分别授权，Agent 本地有最终控制权。
- 低门槛：MVP 用户应在 5 分钟内完成安装、绑定和首次命令执行。

## 5. 平台范围

MVP：

- 控制端：iOS、Android。
- 被控端：macOS Agent。
- 核心能力：终端、文件、基础桌面辅助、设备绑定、加密连接。

V1：

- Windows Agent。
- PowerShell、cmd、WSL 入口。
- 命令收藏、脚本模板、剪贴板增强、弱网优化。

V2：

- 服务状态面板。
- 进程管理。
- 端口查看。
- 日志查看。
- 后台任务。
- 通知告警。

明确不进入 MVP：

- 手机控制手机。
- 企业组织权限。
- RDP / VNC / SSH 聚合入口。
- 高帧率游戏或视频串流。
- 协作共享、审计报表、私有化部署。

## 6. 核心用户流程

### 6.1 首次使用

1. 用户在手机 App 注册或登录账号。
2. 用户在 macOS 安装 Agent。
3. Agent 展示二维码和设备名称。
4. 手机扫码绑定设备。
5. macOS 端确认本机允许该手机连接。
6. 用户选择启用终端能力，桌面和文件能力可分别启用。
7. 手机设备列表出现该 macOS 设备。
8. 用户点击连接，默认进入终端面板。

### 6.2 日常连接

1. 用户打开手机 App。
2. 首页显示最近设备和在线状态。
3. 用户点击设备。
4. App 建立连接，优先 P2P，失败走云中继。
5. 连接成功后进入终端页。
6. 用户输入命令并查看输出。
7. 用户可切换到文件页或画面页。

### 6.3 终端操作

终端页是会话默认页，包含：

- 当前设备名称。
- 当前 Shell 类型。
- 当前目录。
- 命令输出区。
- 多行命令输入框。
- 快捷键条。
- 命令历史。
- 常用命令收藏入口。
- 运行状态、退出码、耗时。

手机端输入优化：

- `Tab` 补全按钮。
- `Ctrl+C` 中断按钮。
- `Ctrl+R` 搜索历史。
- `Esc`、方向键、`Cmd` / `Ctrl`、`Alt` / `Option`。
- 长命令多行编辑。
- 最近命令点选重放。
- 常用命令收藏。

### 6.4 文件操作

文件页是终端的辅助能力：

- 浏览远端目录。
- 和终端共享当前目录。
- 上传文件。
- 下载文件。
- 预览文本文件。
- 复制路径。
- 从终端输出中的路径跳转到文件页。

### 6.5 桌面辅助

画面页用于处理 GUI 场景：

- 查看桌面。
- 点击弹窗。
- 查看浏览器运行结果。
- 操作简单 GUI。

桌面辅助采用极简触控：

- 单指滑动：移动光标。
- 轻点：左键。
- 双击：双击。
- 双指滑动：滚动。
- 双指捏合：缩放画面。
- 双指轻点：右键。
- 右下角仅保留键盘入口。
- 高级功能从边缘面板进入。

## 7. 信息架构

手机 App 主要导航：

- 设备。
- 会话。
- 设置。

会话内主标签：

- 终端。
- 文件。
- 画面。

设备详情：

- 在线状态。
- 最近连接时间。
- 当前网络连接状态。
- 已启用能力：终端、文件、桌面。
- 连接历史。
- 广告或激励资源入口，限会话外展示。

## 8. 广告策略

产品核心能力免费，后续通过客户端广告补贴成本。

广告原则：

- 远控会话中不展示广告。
- 终端、文件、画面页不展示广告。
- 连接中不插屏。
- 会话外页面可展示广告，例如设备列表、连接前、断开后、设置页。
- 激励广告可用于换取额外云中继额度、临时高速通道、更长后台任务保留等高成本资源。

禁止广告场景：

- 命令执行中。
- 文件传输中。
- 远程桌面画面中。
- 断线重连中。
- 权限授权过程中。

## 10. MVP 成功标准

- 新用户 5 分钟内完成 macOS Agent 安装、手机绑定和第一次命令执行。
- 连接成功后默认打开终端，而不是桌面。
- 用户可以完成 `pwd`、`ls`、`git status`、`npm run dev` 等常见命令。
- 断线重连后终端会话和输出可恢复。
- 文件页可以浏览当前终端目录。
- 画面页能处理常见 GUI 弹窗。
- 远控会话中没有广告干扰。
